Hawa Mail — النسخة المحسّنة للحماية

النسخة دي تحافظ على الموقع والوظائف الحالية، وتضيف طبقات حماية مناسبة لموقع Static:
- Content Security Policy (CSP)
- Referrer Policy
- منع بعض النسخ/السحب العشوائي للمحتوى
- Strict Mode في JavaScript
- حقوق Hawa Mail داخل الملفات والواجهة
- لا توجد مفاتيح سرية داخل كود المتصفح

مهم:
موقع Static لا يمكن جعل كوده سريًا 100%؛ الزائر يستطيع دائمًا تنزيل الملفات التي يحتاجها المتصفح. الحماية هنا تقلل العبث والنسخ السهل، وليست حماية مطلقة من النسخ.

النشر على GitHub Pages:
1) ارفع الملفات الأربعة إلى جذر المستودع.
2) تأكد أن index.html في الجذر.
3) Settings > Pages > Deploy from a branch > main > /(root) > Save.
