- حفظ عناوين البريد محليًا.

- QR للبريد الحالي.
- تشفير وفك تشفير AES محليًا.
- Hawa XO ضد الكمبيوتر.
- Hawa Chess خفيف ضد الكمبيوتر.
- إحصائيات محلية.
- Hawa Mail Share عبر Web Share أو رابط المشاركة.
