# Hawa Mail

نسخة GitHub Pages متعددة الملفات من Hawa Mail.

## الرفع على GitHub
1. ارفع **كل الملفات الموجودة داخل هذا المجلد** إلى الـRepository.
2. أهم ملف هو `index.html` ويجب أن يكون في Root.
3. في GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. افتح رابط GitHub Pages بعد اكتمال النشر.

## الملفات
- `index.html` — واجهة الموقع.
- `style.css` — التصميم الأسود والأبيض.
- `script.js` — وظائف البريد والاتصال بـ GrabMail API.

## API
يستخدم GrabMail API العام:
`https://grabmail.io/api/v1`

لا توجد مفاتيح API مطلوبة للنطاق العام، ولا يوجد endpoint لإنشاء صندوق بريد؛ العنوان يصبح فعّالًا عند وصول رسالة إليه. الرسائل تُحذف تلقائيًا بعد 5 أيام، وحد الاستطلاع الموصى به هو طلب واحد في الثانية لكل عنوان.

تنبيه: البريد العام قابل للقراءة لمن يعرف العنوان، لذلك لا تستخدمه للمعلومات الحساسة.
